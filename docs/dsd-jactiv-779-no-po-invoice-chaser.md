## 1. Solution Overview

The No-PO Invoice Chaser is an unattended Cloud API Workflow that queries Coupa daily for draft or new invoices within the past 7 days, filters out credit notes and invoices with linked purchase orders, and sends a Slack Block Kit notification to a team channel when unpaired invoices are found. The automation supports a no-PO-no-pay policy by surfacing invoices that cannot be matched or paid until correctly linked to a purchase order.

**Delivered Components:**

| Project | Product | Role | Entry Point | Trigger |
|---|---|---|---|---|
| `no-po-invoice-chaser-api` | api-workflows | primary | Cloud API endpoint | Orchestrator weekday schedule (10:00 EET/EEST) |

## 2. As-Built Architecture

The solution contains one Cloud API Workflow (`no-po-invoice-chaser-api`) that orchestrates the entire flow with no dispatcher/performer split.

```
┌─────────────────────────────────────────────┐
│     Orchestrator Weekday Trigger (10:00)    │
└──────────────────┬──────────────────────────┘
                   │
        ┌──────────▼───────────────┐
        │ no-po-invoice-chaser-api │
        │   (Cloud API Workflow)   │
        └──────────────┬───────────┘
                       │
      ┌────────────────┼────────────────┐
      │                │                │
  ┌───▼──┐    ┌───────▼────────┐   ┌──▼────┐
  │Coupa │    │ Invoice Filter │   │ Slack │
  │Query │    │  (JavaScript)  │   │ Post  │
  └──────┘    └────────────────┘   └───────┘
```

**Coupa Connection:** Retrieves invoices via HTTP GET to `invoices` endpoint with filters for status, date range, and sort order.  
**JavaScript Filter:** Excludes credit notes and checks for linked PO (`po-number` or `order-header-num` in invoice-lines).  
**Slack Block Kit:** Sends rich notification with count, policy context, and actionable Coupa link.

No deviations from SDD design; reference workflow in `code/no-po-invoice-chaser-779/no-po-invoice-chaser-api/Workflow.json` is the complete implementation.

## 5. Operations Runbook

### Prerequisites

- [ ] Coupa connection `5fadfc73-a372-46ae-a27c-2481741eed07` active and authenticated in Fusion2026 folder.
- [ ] Slack connection `43d506f7-7de2-4798-aac1-9522e2e45dbb` active; token has `chat:write` scope for channel WLX9BD8FN.
- [ ] Slack Bot token asset created and linked to `uipath-salesforce-slack` connection.
- [ ] Production Coupa hostname confirmed if not `uipath-test.coupahost.com` (line 292 of Workflow.json).
- [ ] Orchestrator weekday schedule created for 10:00 EET/EEST trigger (org architectural considerations §1).

### Execution

**Trigger:** Orchestrator schedule, weekdays (Monday–Friday) at 10:00 Romania time.  
**Manual run:** API call to cloud endpoint or `uip api-workflow run` with no input arguments.  
**Expected runtime:** < 2 minutes.

### Normal Run Output

Log entries include:
- Coupa GET request with status, date filters, sort order.
- Invoice count and exclusion reasons (`po-number`, `order-header-num` presence, credit note type).
- Slack payload composed with count, date window, Coupa URL.
- Slack POST response validation.
- Final counts: `qualifying_count` (invoices without linked PO), `slack_sent` (true/false).

### Volume & Scale

- Coupa query limit: 50 invoices per call (hardcoded; no pagination loop).
- Slack message: One per run when count > 0.
- Expected 7-day window: ~194 invoices (per SDD §8); filter reduces to typically 5–15 unpaired.

### Escalation

- **Coupa unavailable:** Check org credentials and Coupa service health; retry via manual schedule trigger.
- **Slack delivery fails:** Verify token scope, channel membership, bot active status; check Slack workspace logs.
- **Auth failures:** Contact Fusion2026 admin to refresh credentials.
- **Unexpected counts:** Validate Coupa filter logic in `code/no-po-invoice-chaser-779/no-po-invoice-chaser-api/Workflow.json:215` (JavaScript_FilterAndCount).
